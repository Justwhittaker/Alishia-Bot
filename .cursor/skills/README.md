# Project skills

Slash-command skills for this workspace. Commit these so they travel with the repo.

| Skill | Command | Purpose |
|-------|---------|---------|
| `shopify_scrape` | `/shopify_scrape <url>` | Scrape a website into Shopify template CSV columns (**always unlisted**) |
| `shopify_scrape_metric` | `/shopify_scrape_metric` | Canvas/table sanity check: products, categories, present vs missing |
| `shopify_csv` | `/shopify_csv` | Convert an existing scraped CSV → Shopify import CSV (**always unlisted**) |
